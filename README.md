Kesan Pertama Menggunakan VS Code

Repository ini berisi catatan pengalaman pertama saya menggunakan Visual Studio Code (VS Code) sebagai text editor untuk belajar coding.

👋 Perkenalan

Halo! Saya Muhammad Yusuf Andriyanto, mahasiswa baru Program Studi D4 Teknik Rekayasa Perangkat Lunak (TRPL) di Politeknik Negeri Cilacap. Ini adalah salah satu langkah awal saya dalam perjalanan belajar programming dari nol.

💻 Kesan Pertama

Saat pertama kali membuka VS Code, hal yang langsung terasa adalah tampilannya yang bersih, ringan, dan tidak membingungkan meskipun ini pertama kalinya saya menggunakan code editor "serius". Beberapa hal yang saya perhatikan:

Tampilan (UI) rapi — sidebar untuk file explorer, area kerja utama, dan terminal terintegrasi tersusun dengan jelas.
Terminal bawaan — tidak perlu membuka aplikasi terpisah untuk menjalankan program, cukup dari dalam VS Code.
Syntax highlighting — kode menjadi lebih mudah dibaca karena warna-warna yang membedakan keyword, variabel, dan komentar.
Ekstensi (extensions) — banyak plugin yang bisa ditambahkan sesuai kebutuhan, misalnya untuk bahasa C yang sedang saya pelajari.
⚙️ Fitur yang Paling Membantu
IntelliSense — bantuan autocomplete yang memudahkan saat menulis kode.
Integrated Terminal — langsung compile dan run program dari editor.
Git Integration — memudahkan tracking perubahan kode dan push ke GitHub.
Multi-language support — cocok untuk belajar berbagai bahasa pemrograman ke depannya.
🧩 Tantangan Awal
Masih beradaptasi dengan shortcut keyboard yang banyak.
Perlu belajar cara mengatur ekstensi dan konfigurasi agar sesuai kebutuhan (misalnya setup compiler C).
Terbiasa dulu dengan alur kerja terminal + editor dalam satu aplikasi.
🎯 Kesimpulan

VS Code terasa sangat cocok untuk pemula seperti saya karena ringan, fleksibel, dan didukung komunitas besar sehingga mudah mencari referensi saat menemui masalah. Repository ini akan saya gunakan sebagai catatan perjalanan belajar coding saya ke depannya.

Dibuat sebagai bagian dari proses belajar programming di Politeknik Negeri Cilacap.
